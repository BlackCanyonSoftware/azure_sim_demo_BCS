    How it works

    1. This page and its API are an Azure Static Web App. You signed in with Microsoft Entra ID, and only the invited operator role reaches the API.
    2. The API puts the job on an Azure Service Bus queue with a key that can only send.
    3. A worker on the home PC holds a key that can only listen. It connects out to the queue (nothing at home is open to the internet), runs the job with MuJoCo on its GPU, and uploads the results.
    4. Results go to Azure Blob Storage, which allows no public reads. The API hands this page links that open one file for 30 minutes.
    5. Application Insights traces both sides, and a budget emails before the credit runs low. The whole Azure side is one Bicep file.
